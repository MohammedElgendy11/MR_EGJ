## 2024-05-20 - VR Button Tactile Feedback Before Scene Transition
**Learning:** VR UI buttons that trigger immediate scene loads can feel unresponsive because the visual click feedback is often obscured by the instant screen freeze during loading. Adding a small, swift visual tactile feedback (like scaling down and up) *before* triggering the scene load provides necessary confirmation to the user that their interaction was registered, significantly improving perceived responsiveness.
**Action:** When implementing scene-transition buttons in VR, wrap the transition logic inside a coroutine that first plays a brief (~0.1s) tactile visual feedback animation using `Time.unscaledDeltaTime` (to avoid timescale bugs), ensuring the user perceives the feedback before the scene unloads.
