## 2024-04-13 - Visual Tactile Feedback for VR Buttons
**Learning:** VR UI buttons lack physical resistance, making it difficult for users to confirm presses. Without visual feedback (like a scale down animation), users often double-press or feel uncertain if their action registered.
**Action:** Always implement a brief scale down/up coroutine animation on interactive VR UI elements to provide immediate, satisfying visual confirmation of interaction.
