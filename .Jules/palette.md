## 2024-05-28 - Adding visual feedback to VR buttons
**Learning:** In VR interfaces, immediate visual tactile feedback (like scaling a button down slightly when clicked) is critical because users lack the physical resistance of a real button. Without it, users may think their interaction didn't register, especially if there's a slight delay before a scene transition or network request. Furthermore, such animations must use `Time.unscaledDeltaTime` so they aren't paused if the game is paused, and `SceneManager.LoadScene` should be triggered *after* the tactile feedback plays so the user actually sees it.
**Action:** When implementing interactive buttons, always add a visual micro-interaction (like a coroutine scale animation) before triggering functional logic like scene changes. Cache initial state in `Awake` and restore in `OnDisable` to avoid state bugs.
