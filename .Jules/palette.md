## 2025-04-08 - Added VR Tactile Feedback Scale Animation
**Learning:** VR users benefit greatly from clear visual and tactile feedback on interactive surfaces. A brief scale down animation upon button press gives immediate acknowledgment to the user. Care must be taken with coroutines used for UI feedback, particularly that they check `gameObject.activeInHierarchy` before starting to avoid Unity errors, and reset states properly in `OnDisable` using the original values stored in `Awake` rather than hardcoded vectors, to avoid overriding custom Inspector scales.
**Action:** When adding interaction states to generic UI buttons in VR setups, include a lightweight scale Coroutine pattern that caches initial scale and gracefully handles GameObject lifecycle events (Awake, OnDisable).
