
## 2024-04-04 - VR Button Tactile Feedback Animation
**Learning:** Virtual Reality (VR) environments often lack tactile feedback for UI interactions, causing users to be unsure if a button press registered. Relying solely on audio or color changes can be insufficient, especially for accessibility. A quick, small scale animation provides a clearer visual confirmation of interaction that mimics physical button depression. Furthermore, UI animations relying on coroutines inside Unity can easily break or cause errors if states aren't reset properly (e.g., when the object is disabled mid-animation) or if the `activeInHierarchy` state isn't checked before starting the coroutine.
**Action:** When adding interaction animations (like a scale down/up) in Unity for VR or 3D UI, always cache the initial state (like scale) in `Awake()`, reset it and stop any active coroutines in `OnDisable()`, and verify `gameObject.activeInHierarchy` before invoking `StartCoroutine` to ensure stability and compatibility with custom Inspector properties.
