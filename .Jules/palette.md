## 2024-05-04 - Visual Tactile Feedback for VR UI Buttons
**Learning:** VR UI elements should provide visual tactile feedback (like scaling down and up on interaction) to ensure the user perceives the interaction. Using `Time.unscaledDeltaTime` instead of `Time.deltaTime` for these coroutine animations is critical to prevent the animation from hanging indefinitely if the game's timescale is set to 0 (e.g., during a pause menu or game over state).
**Action:** Always implement a brief scale down/up coroutine animation on interaction for VR UI buttons using `Time.unscaledDeltaTime`. Cache the original scale in `Awake` and restore it in `OnDisable` to prevent state corruption upon interaction interruption. Delay the functional action (e.g., scene load) until the end of the visual tactile feedback coroutine.
