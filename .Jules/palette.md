## 2024-05-18 - [Add visual/tactile feedback to VR buttons]
**Learning:** Unity UI components utilizing coroutines for temporary states (like button press scaling down and up) can leave the component in an incorrect state if the object is disabled before the coroutine finishes, or if a new coroutine is started without stopping the old one. This disrupts the custom initial Inspector scales of prefabs. Also, unity will throw errors if `StartCoroutine` is called on a disabled object.
**Action:** When implementing UI feedback animations via Coroutines, always cache the initial state (e.g. `_initialScale = transform.localScale` in `Awake()`), restore that state in `OnDisable()`, stop existing coroutines before starting new ones, and check `gameObject.activeInHierarchy` before calling `StartCoroutine()`.
