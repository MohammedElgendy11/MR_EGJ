## 2024-05-24 - Tactile Feedback for Scene Transitions in VR
**Learning:** VR users need tactile visual feedback (like button scaling) to confirm their interaction. If functional actions (like scene loads) trigger immediately, the feedback animation is never seen because the object or scene unloads first. Also, time-based animations must use `Time.unscaledDeltaTime` so they don't hang if the game is paused or the timescale is zero. Finally, always cache and restore initial state (`originalScale` in `Awake`/`OnDisable`) to prevent state corruption if animations are interrupted.
**Action:** When creating UI buttons that trigger scene changes or unload objects, start a coroutine to play the visual feedback *before* executing the functional action, use `unscaledDeltaTime`, and always restore the original transform state in `OnDisable()`.
