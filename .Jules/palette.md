## 2025-04-06 - VR Tactile Visual Feedback Lifecycle Management
**Learning:** Adding coroutine-based visual feedback (like scaling a button on press) for VR tactile consistency is a great micro-UX enhancement, but improper lifecycle management can lead to broken UI states. For example, if a button with custom Inspector scaling gets deactivated mid-animation, a hardcoded return to `Vector3.one` upon reactivation will override the designer's intent.
**Action:** Always cache the `initialScale` in `Awake()`. Before starting a coroutine, check `if (gameObject.activeInHierarchy)` to prevent starting coroutines on inactive objects. Most importantly, handle state resets in `OnDisable()` by stopping any active coroutines and resetting `transform.localScale` to the cached `initialScale`.
