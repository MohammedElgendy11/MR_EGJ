## 2024-03-20 - [Visual Feedback for VR UI Buttons]
**Learning:** [VR UIs lack tactile feedback; simulating tactile response via visual scale animation (0.9x scale over 0.1s) significantly improves user understanding of interactive elements. Moreover, safely handling animation coroutines with custom Inspector properties requires caching `initialScale` in `Awake()`, checking `gameObject.activeInHierarchy` before starting coroutines to prevent initialization exceptions, and resetting scale in `OnDisable()` to prevent permanent deformation issues when objects are deactivated mid-animation.]
**Action:** [Consistently apply this scaling micro-animation pattern to interactive VR elements. Ensure coroutines verify hierarchy active status, stop previously active instances, cache the initial transform metrics dynamically at start rather than hardcoding "1.0", and restore states during `OnDisable()`.]
