## 2024-03-04 - [Tactile VR Feedback Animations]
**Learning:** [Interactive UI elements in VR (like KeypadButton and HintButton) need coroutine-based scale animations (scaling down and back up) to provide immediate tactile visual feedback upon interaction. However, rapid interactions can cause these animation coroutines to stack leading to visual glitches. Furthermore, if a UI element is deactivated while animating, it retains its scaled state, breaking the layout upon reactivation.]
**Action:** [Always cache and stop existing animation coroutines before starting a new one. Crucially, always implement `OnDisable` to reset the object's `transform.localScale` to `Vector3.one` (or its default scale) to prevent layout issues if the object's active state changes mid-animation.]
