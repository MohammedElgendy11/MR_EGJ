## 2025-04-05 - Added tactile feedback to Puzzle UI buttons
**Learning:** VR users benefit from immediate visual feedback on UI components to confirm interaction. Scaling a button down slightly (`0.9x`) and back over a short duration (`0.1s`) creates a satisfying "tactile" feel. However, when implementing this via Unity Coroutines on UI elements that might be disabled (e.g. closing a hint panel), the coroutine throws errors if the GameObject is inactive, and the scale can get stuck at the smaller size if not reset.
**Action:** When adding coroutine-based animations to UI elements, always verify `gameObject.activeInHierarchy` before calling `StartCoroutine`. Additionally, cache the original scale in `Awake()`, and use `OnDisable()` to stop any running animation coroutines and reset the `transform.localScale` back to the cached initial value to prevent cumulative scaling bugs.
