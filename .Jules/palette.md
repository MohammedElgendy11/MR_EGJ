## 2024-10-26 - Unity UI Button Feedback Coroutines
**Learning:** Standard UI scaling animations on buttons that trigger terminal actions (like scene loading) are critical for tactile feedback in Unity, but they introduce state management complexity. Spam-clicking during the short visual transition can restart the coroutine or trigger the action multiple times. Furthermore, if a game-over screen is paused (Time.timeScale = 0), standard Time.deltaTime will freeze the UI animation indefinitely.
**Action:** Always implement a boolean guard (e.g., `_isTransitioning`) to early-return on subsequent clicks, use `Time.unscaledDeltaTime` for the visual transition, and cache/restore the original scale in `Awake`/`OnDisable` to prevent state corruption across enable/disable cycles.
