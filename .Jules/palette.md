## 2024-05-24 - VR UI tactile feedback and Scene transitions
**Learning:** In VR UIs, immediate visual tactile feedback (like scaling elements down/up on click) is critical for confirming interactions. However, if these elements trigger scene transitions (like a 'Play Again' button calling `LoadScene`), the transition often occurs instantly, interrupting the animation and preventing the user from perceiving the feedback. Furthermore, animations must use `Time.unscaledDeltaTime` so they don't hang if the game's timescale is 0.
**Action:** When implementing UI interaction animations that trigger scene transitions, always run the animation first (using a coroutine with `unscaledDeltaTime`) and delay the functional action (e.g., `SceneManager.LoadScene`) until the visual feedback coroutine has completed. Cache the original scale in `Awake` and restore it in `OnDisable` to handle interruptions safely.
