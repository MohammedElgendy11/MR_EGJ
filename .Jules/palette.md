## 2026-05-24 - Tactile UI Feedback for Unity VR/Mobile
**Learning:** Adding subtle scale-down/up coroutine animations on interactive UI elements (like buttons) provides immediate visual tactile feedback, enhancing the feeling of responsiveness and bridging the gap between interaction and the resulting action (like a scene transition). It is important to cache and restore the original scale in `Awake` and `OnDisable` to prevent the UI from becoming permanently scaled down if the coroutine is interrupted by a scene change or UI disable.
**Action:** When implementing interaction feedback for UI elements that trigger heavy operations or scene loads, always use a quick scaling coroutine and explicitly manage the starting and ending scale state using `Time.unscaledDeltaTime` so the animation completes even if the game is paused.
